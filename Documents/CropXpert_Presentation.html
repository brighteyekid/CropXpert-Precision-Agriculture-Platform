Hardware Module

Field-grade sensing at INR 3,600

A four-sensor array on Arduino UNO / ESP32 measures everything the ML model needs — in seconds, not lab weeks.

S-01

RS485 NPK Sensor

Modbus RTU via MAX485 converter. Reads Nitrogen, Phosphorus, Potassium in mg/kg. Range 0–1999, accuracy ±2%. Replaces laboratory testing at 1/500th the cost.

S-02

Analog Soil pH Sensor

0–14 pH range, ±0.1 resolution. Analog input on Arduino pin A0. Identifies acid/alkaline imbalance before planting.

S-03

Capacitive Moisture Sensor

Volumetric water content 0–100%. Capacitive design — no corrosion in field conditions. Longer field life than resistive types.

S-04

DHT22 Temp / Humidity

±0.5°C temperature, ±2–5% humidity. Rainfall auto-fetched from OpenWeatherMap API using farmer GPS — no manual entry.

Novel Contribution I

Market-Aware Recommendation Engine

Every reviewed prior system recommends crops on agro-climatic suitability alone — ignoring whether the crop will actually sell. CropXpert is the first Indian precision agriculture system to integrate live Minimum Support Price data from AGMARKNET into the ranking formula.

Score(c) = 0.60 × PML(c)
+ 0.25 × MSP_Index(c)
+ 0.15 × SeasonDemand(c)
// α + β + γ = 1.0 (configurable)
α 0.60

ML Probability Score

Random Forest confidence for the crop given the sensor readings. Dominant weight — agronomic fit is primary.

β 0.25

MSP Market Index

Live Minimum Support Price & mandi arrival data fetched from AGMARKNET government API. 24-hour SQLite cache.

γ 0.15

Seasonal Demand

Month-adjusted mandi arrival volume proxy — down-ranks crops with surplus supply at time of sowing.

A crop with high ML confidence but suppressed market price is ranked below a slightly less optimal but economically viable alternative.
Data Sources

Live Government APIs

AGMARKNET (agmarknet.gov.in) — official mandi price portal from the Directorate of Marketing & Inspection, Government of India. OpenWeatherMap One Call 3.0 for rainfall. MyScheme.gov.in for welfare schemes.

Key insight

The Market Intelligence Layer runs asynchronously — MSP data is cached for 24 hours, adding zero latency to the 2.3 ms ML inference path. Final recommendation is produced in under 5 ms end-to-end.

System Architecture

Seven-Layer Microservices Platform

Microservices over an MQTT event bus — selected over monolithic and serverless patterns for independent deployability, heterogeneous hardware integration, and offline resilience.

Layer 1 — Physical Sensing — RS485 NPK, pH, Moisture, DHT22
Layer 2 — Edge / Communication — Arduino UNO, ESP32, Mosquitto MQTT
Layer 3 — ML Inference — FastAPI + Random Forest (2.3 ms, 4.7 MB)
Layer 4 — Market Intelligence — AGMARKNET MSP Scorer
Layer 5 — Presentation — React 18 PWA, react-i18next, 4 languages
Layer 6 — Bot Gateway — Twilio WhatsApp + MSG91 SMS fallback
Layer 7 — External APIs — AGMARKNET, OpenWeatherMap, MyScheme.gov.in

Novel Contribution III

CropBot — No Smartphone, No Problem

The WhatsApp/SMS CropBot eliminates the smartphone and internet dependency — reaching farmers who own nothing more than a basic keypad phone. A first in Indian precision agriculture.

Natural Language Queries

Roadmap

From Prototype to Pan-India Scale

A phased roadmap extending the platform from its current prototype into a nationwide offline-capable precision agriculture network — aligned with India's Digital Agriculture Mission.

Current — v1.0 — Done
Core Platform
Arduino UNO + RS485 NPK + pH + moisture + DHT22. Random Forest (99.2%, 2.3 ms). React PWA with 4 languages. WhatsApp/SMS CropBot. Government Scheme Portal. Hardware BOM INR 3,600.
v1.1 — In Progress
Market Intelligence Layer
Full AGMARKNET MSP integration with 24-hr cache. Weighted scoring formula live. Soil Health Dashboard RAG indicators. Farm Profit Calculator per-crop.
v2.0 — Roadmap
LoRa Offline Extension
Replace ESP8266 Wi-Fi with ESP32 + LoRa SX1276 (915 MHz). 5–15 km range at <20 mA. RAK2245 LoRaWAN gateway supporting 1,000 sensor nodes. PM-WANI backhaul integration. Targets Chhattisgarh, Jharkhand, NE India.
v2.1 — Future Research
Satellite NDVI Fusion
Cross-reference ground NPK sensor readings with Sentinel-2 satellite NDVI values (4.2% accuracy gain demonstrated by Sharma et al., 2021). Field validation in Punjab and Maharashtra.
v2.2 — Future Research
Crop Disease Detection
TFLite leaf-image classifier deployed on ESP32-CAM. On-device inference for crop disease detection without cloud dependency. Expands the advisory from soil to visible plant health.
v3.0 — Scale
KVK Field Deployment
Deploy SMS bot in collaboration with Krishi Vigyan Kendra (KVK) extension centres. Expand crop database from 22 to 50+ varieties. Add state-level agro-climatic calibration for all 28 Indian states.
